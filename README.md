# Countgrove 1.0 TEST
Native Java/Canvas Android 8+ Renkatsu printed-number region puzzle.

Fence the entire printed-number grid into edge-connected regions. Each region of N cells must contain every number from 1 through N exactly once. Number order does not matter. Regions may have any connected shape; a single printed 1 may stand alone. All printed numbers stay fixed. Tap internal edges to add or remove fences. No extra fence may lie inside a connected region. Twelve unique 4x4 printed boards have twelve distinct partitions.

Saved count palette and region colors, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Python connected-candidate enumeration and exact-cover search prove one partition for each printed board. Java compares that independently proven solution lookup against production floodfill and complete value-set checks for all 12 solutions plus 20000 random 24-wall masks per board. Bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, edge taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 96 recovered READMEs and recent cumulative stage/release records found no Renkatsu match. Shared Bendwillow fence interaction is disclosed, but arbitrary connected regions containing complete printed 1-through-N sets replace L geometry and knee clues. Unlike Ripplegrove, players draw regions around fixed digits instead of filling digits into fixed rooms with spacing constraints. Kuroclone and Nawabari candidates were rejected as existing Cedarclone and Willowcourt mechanics. Known Renkatsu genre, not a global invention.
